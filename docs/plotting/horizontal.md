# Horizontal Plots

Horizontal maps show the spatial distribution of snow cover and snow water equivalent across Europe.

All scripts are located in `plotting_py/HORIZONTAL/`.

---

## What is Plotted

- **Snow cover duration** and **snow water equivalent**
- For the time slices: **1971–2000**, **2021–2050**, **2070–2099**
- As **absolute values** or **differences**, including **robustness** information

---

## How to Run

Use the environment snow.yml

Use the Jupyter notebook:

```
plotting_py/HORIZONTAL/horiplot-snow.ipynb
```

Helper functions are stored in:

```
plotting_py/HORIZONTAL/plotting_tools_snow.py
```
