# Annual Cycle Plots

Annual cycle plots cover the period **September to August** for the following indices:

- Number of snow days
- Snow covered area (SCA)
- Snow water equivalent (SWE)

All scripts are located in `plotting_py/ANNUAL_CYCLE/`.

---

## Scripts Overview

### All regions, time slices and scenarios on one sheet

```bash
python plot_annual_cycle_all_rcps_all_regions.py
```

Inside the script, select which index to plot. The y-axis is variable.

---

### All height levels for 4 Prudence regions per scenario

```bash
python plot_annual_cycle_all.py
```

---

### All scenarios for a single region

```bash
python plot_annual_cycle_all_rcps_region.py
```
